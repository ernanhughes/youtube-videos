# Roadmap and acceptance gates

## YT02 — Code Demonstration Engine

Build a plugin that extracts runnable code units, reconstructs incremental implementation steps, launches an isolated working directory/container or restricted process, records stdout/stderr/exit codes/timeouts, and rejects unexpected network/file access. Build tests using one deliberately failing case and one passing case. No invented output in video scenes. Integrate CoCoder's actual versioned walkthrough contract only after independently verifying it.

## YT03 — Evidence and research verification

Crawl cited URLs in bounded batches; store retrieved content hashes, dates and licensing, verify exact claims, distinguish unsupported from contradicted. Manuscript claims are not independent proof. Reviewer must accept the evidence map.

## YT04 — Visuals and audio

Slide renderer, code-typing scenes, Mermaid, screen capture, synthetic narrator adapter with provider-specific license/privacy policy. FFmpeg timeline with subtitles, still/scene duration, audio levels and export quality checks. No optional plugin can skip the final QA gate.

## YT05 — Publishing

YouTube OAuth adapter, metadata generation, copyright/license review, thumbnail, scheduled upload, provenance manifest. Upload must be separate from draft approval and require explicit user command and preview acceptance.

## YT06 — Multi-book production

Catalog site-wide books and series, reusable series branding, chapter/episode order, localization, downloadable code, attribution, citation overlays and episode variants for blog articles versus full chapters.
